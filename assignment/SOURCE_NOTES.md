# Исходные материалы по заданию

Этот файл содержит сырые заметки с лекции.

Claude не должен считать формулировки ниже идеально точной спецификацией.
Если заметки противоречат друг другу или допускают несколько трактовок,
необходимо зафиксировать неоднозначность.

## Мои заметки

1. RSA - 32768
2. Кузнечик
3. Стрибог - 512
4. ЭЦП
5. NFA / 3FA
6. Форма регистрации (+ регулярки)
7. Форма восстановления пароля
8. Коды восстановления пароля / коды одноразовые
9. Почтовый сервер для 3FA

Дополнительные заметки:

- 1–4 делаем по ГОСТу
- Стрибог нужен для хэширования паролей в БД с солью
- роли: гость, пользователь, админ
- пользователь входит в систему и вводит сообщение
- сообщение можно зашифровать двумя способами:
    - RSA
    - Кузнечик
- пользователь может посмотреть список зашифрованных сообщений
- каждое сообщение можно скачать вместе с электронной подписью в PDF
