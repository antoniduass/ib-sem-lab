# ib-sem-lab

Учебное веб-приложение по информационной безопасности — «защищённый блокнот».
Пользователь входит в систему в три шага, пишет сообщение, шифрует его RSA-32768
или Кузнечиком, подписывает своей ЭЦП по ГОСТ и скачивает в PDF с подписью.

Вся криптография написана вручную, без готовых криптобиблиотек, и проверена
контрольными примерами из стандартов. Требования — [`assignment/SPEC.md`](assignment/SPEC.md).

| Блочный шифр Кузнечик | ГОСТ 34.12-2018 | ✅ готово, контрольные примеры ГОСТа |
| Модульная арифметика, тест простоты Миллера — Рабина | — | ✅ готово |
| ЭЦП на эллиптической кривой (512 бит, `paramSetA`) | ГОСТ 34.10-2018, RFC 7836 | ✅ готово, контрольные примеры ГОСТа и RFC |
| RSA-32768 | — | в планах |
| Режим гаммирования (CTR) для Кузнечика | ГОСТ 34.13-2018 | в планах |
| Хранение паролей: PBKDF2 на Стрибоге | RFC 7836, RFC 9337 | в планах |
| Регистрация, вход в три фактора, роли | — | в планах |
| Почта на localhost, восстановление пароля, коды | — | в планах |
| Сообщения, PDF с подписью, администрирование | — | в планах |

## Структура

- `gostcrypto/` — криптография, не зависит от веб-части;
- `app/` — веб-приложение на Flask;
- `tests/` — автоматические тесты;
- `assignment/` — задание, спецификация и стандарты.

Подробная карта репозитория — [`PROJECT_MAP.md`](PROJECT_MAP.md).

## Требования

- Python 3.13
- [uv](https://docs.astral.sh/uv/)
- PostgreSQL

## Установка

```bash
uv sync
cp .env.example .env
```

В `.env` укажите строку подключения к PostgreSQL в `DATABASE_URL`.

## Запуск

```bash
set -a; source .env; set +a
uv run flask --app app run
```

Проверка: `http://127.0.0.1:5000/health` возвращает `{"status": "ok"}`.

## Тесты и проверки

```bash
uv run pytest
uv run ruff check
uv run ruff format --check
```
