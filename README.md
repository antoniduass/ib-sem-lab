# ib-sem-lab

Учебное веб-приложение по информационной безопасности — «защищённый блокнот».
Пользователь входит в систему в три шага, пишет сообщение, шифрует его RSA-32768
или Кузнечиком, подписывает своей ЭЦП по ГОСТ и скачивает в PDF с подписью.

Вся криптография написана вручную, без готовых криптобиблиотек, и проверена
контрольными примерами из стандартов. Требования — [`assignment/SPEC.md`](assignment/SPEC.md).

## Требования

## Установка

```bash
uv sync
cp .env.example .env
```

### База данных

Проект использует собственный кластер PostgreSQL в `instance/pgdata` (порт 5433,
только localhost, без пароля) — так он не зависит от других установок PostgreSQL:

```bash
initdb -D instance/pgdata -U ib --auth-local=trust --auth-host=trust -E UTF8 --locale=C
pg_ctl -D instance/pgdata -o "-p 5433 -c listen_addresses=localhost" -l instance/postgres.log start
createdb -h localhost -p 5433 -U ib ib
createdb -h localhost -p 5433 -U ib ib_test
set -a; source .env; set +a
uv run flask --app app init-db
```

Остановить кластер: `pg_ctl -D instance/pgdata stop`. База `ib_test` нужна тестам
(адрес — `TEST_DATABASE_URL`), тесты очищают её таблицы.

## Запуск

```bash
set -a; source .env; set +a
uv run flask --app app run
```

Проверка: `http://127.0.0.1:5000/health` возвращает `{"status": "ok"}`.
Страницы: `/register` — регистрация, `/login` — вход, `/account` — кабинет,
`/admin` — администрирование (только администратор).

Роли: гость, пользователь (назначается при регистрации), администратор.
Первого администратора назначает команда:

```bash
uv run flask --app app set-role <логин> admin
```

Сессии хранятся на сервере, в PostgreSQL: в cookie — только случайный токен
(HttpOnly, SameSite=Lax), в базе — его хэш Стрибогом-512; при входе токен меняется,
сессия живёт час с последнего запроса. Все формы защищены CSRF-токеном.
Роль проверяется на сервере для каждой закрытой страницы.

Пароль хранится как PBKDF2-HMAC-Стрибог-512 (RFC 9337): случайная соль 16 байт,
1000 итераций, хэш 64 байта. Регистрация занимает около 1,3 с — это цена итераций
на самописном Стрибоге.

## Ключ RSA-32768

Ключ системы создаётся один раз и хранится в `instance/` (не попадает в Git):

```bash
uv run python -m gostcrypto.rsa instance/rsa_private_key.json
```

На 8 ядрах (Apple Silicon) генерация заняла 19 минут. Простые числа ищутся параллельно
на всех ядрах, кандидаты заранее отсеиваются делением на простые до миллиона.
Шифрование — доли секунды, расшифрование одного блока (до 4085 байт) — около 30 секунд.

Для демонстрации подойдёт ключ на 2048 бит — он создаётся за доли секунды:

```bash
uv run python -m gostcrypto.rsa instance/rsa_demo_2048.json 2048
```
